# StackOverflow made us smarter?

Struggle is essential for deep learning. I had a realization the other day: StackOverflow is totally gone from the average developers workflow cycle. Countless tabs of StackOverflow pages has been replaced by \<insert your LLM provider of choice\>. At my work we use Gemini and I count over 8 different tabs were I'm asking software development questions. *We're asking for solutions instead of searching for them.* 

There is something magical to be able to have a conversation about your code and easily drop in your code and get your answer tailored to your situation.

But is this trade off always worth it?

## Combining multiple partial answers into your own complete solution

In college I'd often run into some syntax error or quirk of working in a particular language. Often that was python for me. So I'd search for an answer, often find a similar question on StackOverflow, read the solution and comments then try it out. Often it worked, sometimes it didn't. This is where the hard work started. Is the accepted answer wrong? Was the question not asking what I actually care about? Are they using a different version of the language? Each of these require their own search. Probably not answering the direct question I'm there for but each expanding my understanding of the problem space. 

Did I enjoy reaching the Changelog for minor & patch updates? No... Did it help me boil down some random problem that I felt like only I was facing? Defiantly
